# Support

## Community support

For reproducible bugs and feature proposals, use GitHub Issues and follow the repository templates.

Do not post credentials, customer data, private infrastructure details, or security vulnerabilities in public issues.

## Security

See [SECURITY.md](SECURITY.md) for security reporting guidance.
